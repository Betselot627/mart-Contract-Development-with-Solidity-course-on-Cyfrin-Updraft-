# 📘 Solidity 101 - Section 4: AI Prompting, Asking Questions & Getting Help

## 📋 Section Overview

Section 4 focuses on **essential soft skills** for blockchain development: how to effectively use AI tools, ask good questions, and find help when stuck.


---

## 🎯 Learning Objectives

| # | Objective |
|:--|:---|
| 1 | Effectively use AI tools (ChatGPT, Phind, Claude) |
| 2 | Ask well-formatted, answerable questions |
| 3 | Set up GitHub as a development portfolio |
| 4 | Use SpeedRunEthereum for extra practice |
| 5 | Research and solve problems independently |

---

## 🤖 Recommended AI Tools

| Tool | Best For |
|:---|:---|
| **ChatGPT** | General coding, fast answers |
| **Phind** | Web-search + current info |
| **Claude** | Long code, security audits |

> ⚠️ **Always verify AI answers** — AI makes mistakes!

---

## 💡 7 Tips for Success

1. Read the **written lessons** (not just videos)
2. **Copy-paste code** from written lessons
3. **Test AI responses** before trusting them
4. **Format questions properly** (see template below)
5. **Build your GitHub portfolio** (valuable for jobs)
6. Use **SpeedRunEthereum** for extra practice
7. **Engage with the community** (Discord + GitHub)
