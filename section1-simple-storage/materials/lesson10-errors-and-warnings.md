# Lesson 10: Errors and Warnings in Solidity

## Key Concepts

### Color Coding in Remix IDE
- **Red** = Error — your code will NOT compile, you must fix it before deploying
- **Yellow** = Warning — your code works but something could be improved or is risky
- **No color** = All good, code is clean

### Common Errors
- Missing semicolon `;` at end of a line
- Wrong data type used
- Calling a function that doesn't exist
- Using a variable before declaring it

### Common Warnings
- Unused variables
- State variable visibility not explicitly set
- Function can be restricted to `pure` or `view`

## How to Fix Errors

1. **Read the error message carefully** — it tells you the line number and what's wrong
2. **Use AI tools** (ChatGPT, Phind) — paste the error and ask what it means
3. **Search online** — Stack Exchange and GitHub Discussions have most answers
4. **Ask on Discord** — Cyfrin has an active community at discord.gg/cyfrin
